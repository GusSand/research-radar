## 01 · [Why Do Aligned LLMs Remain Jailbreakable: Refusal-Escape Directions, Operator-Level Sources, and Safety-Utility Trade-off](https://arxiv.org/abs/2605.08878)

`mech-interp` `AI security` `preprint` — Yu Chen, Yuanhao Liu, Qi Cao (Institute of Computing Technology, Chinese Academy of Sciences) — arXiv preprint (May 2026)

Introduces Refusal-Escape Directions (RED): local perturbation directions around a harmful input that shift the model's behavior from refusal to compliance while preserving harmful-semantics interpretation. A jailbreak is reframed as a discrete prompt construction that approximates movement along RED, grounding the phenomenon mechanistically. RED arises through the model's operator structure and decomposes into operator-level source contributions; its elimination induces a provable safety-utility trade-off, showing that perfectly closing RED while preserving capability is not achievable by fine-tuning alone. The framework predicts that alignment methods targeting refusal behavior at the output level will remain susceptible to RED-based bypasses until the underlying subspace structure is addressed.

![Figure 1: Refusal-Escape Directions — local perturbation directions from refusal to compliance near harmful inputs](https://arxiv.org/html/2605.08878/x1.png)

*Figure 1: RED as a continuous analogue of jailbreaks — perturbation directions in embedding space around harmful inputs that shift refusal to compliance; decomposition into operator-level sources identifies which model components contribute most to escape.*

## 02 · [Grammar-Constrained Decoding Can Jailbreak LLMs into Generating Malicious Code](https://arxiv.org/abs/2606.11817)

`AI security` `preprint` — Yitong Zhang, Shiteng Lu, Jia Li — arXiv preprint (June 2026)

Grammar-Constrained Decoding (GCD) enforces syntactic validity in code generation and is widely used as a reliability tool. This paper exposes GCD as an attack surface: CodeSpear shows that applying a benign code grammar constraint is sufficient to bypass safety alignment and induce malicious code generation, because the grammar's structural priming shifts the generation distribution into a code-conditioned mode where safety guardrails are less active. The companion defense, CodeShield, aligns the model in the code modality by training it to generate honeypot code (functionally harmless, syntactically valid) under attacker-controlled grammar constraints, robustly preserving safe behavior without degrading normal code generation performance.

![Figure 1: CodeSpear attack — GCD constraint shifts generation into code-conditioned mode bypassing safety](https://arxiv.org/html/2606.11817/x1.png)

*Figure 1: A benign syntax grammar constraint (GCD) applied to a safety-aligned LLM elicits malicious code by priming the code-generation mode; CodeShield defends via honeypot code alignment.*
