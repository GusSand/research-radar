### 1. [**ShadowBench: Exposing Lexical Anchoring and the Illusion of Forgetting in Large Language Models**](https://arxiv.org/abs/2611.15925)

`alignment` `unlearning` `peer-reviewed` — Sujan Maharjan, Lu Liu — **NeurIPS 2026 Datasets & Benchmarks Track (accepted)**

- **Why it ranks here:** Provides the first systematic evidence that current LLM unlearning methods produce superficial output filters rather than parametric erasure — directly undermining the safety assumption that fine-tuning-based forgetting can selectively remove sensitive knowledge.
- **Technical summary:** The paper introduces a Dual-Trait Association (DTA) benchmark where model knowledge must be retrieved without the target entity's name token. Across all evaluated unlearning methods (Gradient Difference, NPO, and variants), models performing near 0% on direct queries reconstructed the "forgotten" entity through latent reasoning traces in over 74% of cases (Latent Entity Leakage Rate), and reached 60–90% shadow accuracy on niche entities via implicit attribute correlations. The benchmark includes GPT-5.4 and Claude-Sonnet-4.6 baselines which both drop 20%+ in accuracy when the entity name is withheld, confirming the lexical anchoring effect is model-agnostic. The authors conclude that none of the evaluated methods achieves true parametric erasure.

### 2. [**Safety as a Budget: Calibrating the Control Channel of Constrained GRPO for Vision-Language Models**](https://arxiv.org/abs/2611.16628)

`safety` `alignment` `preprint` — Anonymous — arXiv preprint, 2026-11-13

- **Why it ranks here:** Delivers a theoretically grounded and empirically validated method for setting explicit safety targets in RL-trained VLMs, exposing two hidden failure modes in standard GRPO that cause safety constraints to silently deactivate.
- **Technical summary:** The paper proposes two-channel constrained GRPO, which separates the base reward channel (used for within-group advantage normalization) from the penalty channel (Lagrange constraint enforcement), and fits the penalty through a monotone map calibrated on judge-labeled responses. Standard GRPO's group-level normalization was found to cancel Lagrange multiplier signals before they reach the gradient; a scorer bias further caused multipliers to saturate or switch off. On Qwen3-VL-2B with a 4B scorer, harm rate fell from 8.9% to 4.8% across 1,037 adversarial prompts (all seeds), with the largest gain on image-embedded intent (10.1%→5.1%); on the unseen HADES benchmark, harm dropped from 28.9% to 12.8%. Over-refusal stayed at ≤2% and MMBench accuracy was unchanged.

### 3. [**Goal Encoding in LLMs**](https://arxiv.org/abs/2611.17297)

`mech-interp` `preprint` — Anonymous — arXiv preprint, 2026-11-13

- **Why it ranks here:** Provides the first causal, plastic, and sustained evidence that transformers internally represent future sub-goals — a key question for understanding whether frontier LLMs are goal-directed and how that could be monitored or steered.
- **Technical summary:** The authors construct a multi-stage coding benchmark and use attention-head probing to localize sub-goal representations. They identify a sparse set of attention heads whose outputs encode the model's upcoming sub-goal before execution, decodable into natural-language descriptions. Three causal properties are established: altering the encoding changes the action (causal); moving it into a different programming language produces the same logical operation (plastic); and the encoding persists through the action's execution across the token span (sustained). The results support a "non-recurrent goal-seeking" (NRGS) account in which the model repeatedly re-reads the goal from context, compares it against visible progress, and continues accordingly — with targeted causal interventions ruling out alternative accounts.

### 4. [**Lazare, veni foras: Reprogramming Dormant Neurons to Backdoor AI Agents**](https://arxiv.org/abs/2611.15118)

`safety` `security` `preprint` — Anonymous — arXiv preprint, 2026-11-13

- **Why it ranks here:** Demonstrates that any frontier model can be turned into a backdoored agent by editing fewer than 10 neurons in closed form — with no retraining — establishing a novel, extremely low-cost supply-chain attack that bypasses standard weight audits at full precision.
- **Technical summary:** The Lazarus method targets dormant neurons (neurons with near-zero activation on natural inputs) in the final feed-forward block. For a P-token payload, approximately P neurons are edited using closed-form weight updates (optionally refined with a few hundred gradient steps); the trigger is any string in context. On Nemotron-Terminal-8B, 7 of >12,000 neurons — fitted on only 23 trigger/no-trigger trajectories — fired the payload on ≥98.8% of triggered test trajectories with zero leakage on clean inputs. The attack transferred to Qwen3.6-27B and Gemma-4-31B-IT. The proposed audit defense detects 91.4% of edited checkpoints at 9.7% FPR. Notably, the core insight was reportedly discovered autonomously by Claude Code with Opus 4.5 during assisted exploration.

### 5. [**CapLite: Prompt-Injection Defense for Small Language Model Agents without Model-Written Security Artifacts**](https://arxiv.org/abs/2611.17115)

`security` `preprint` — Anonymous — arXiv preprint, 2026-11-13

- **Why it ranks here:** Achieves zero successful prompt injection attacks across 13,935 AgentDojo episodes while using 18% of CaMeL's token budget — by eliminating the reliance on model-generated security artifacts that fail on small models.
- **Technical summary:** Existing enforcement defenses (CaMeL, Progent, IPIGuard, DRIFT) require the agent's own model to generate a security artifact (a program, privilege policy, or constraint list); on 15 tested open-weight models, these artifacts allowed attacks in 11–14 models. CapLite instead derives its policy deterministically from tool schemas and commits to all write calls before reading any tool result, allowing a write only if every argument determining its recipient, amount, or destination was stated in the original user request. The resulting guarantee is that injected content cannot add or redirect a write. On the AgentDojo benchmark (13,935 attacked episodes), zero successful attacks were observed; task utility was 29.0% (comparable to CaMeL's 27.2%) at 17.1k tokens per episode vs. CaMeL's ~96k.

### 6. [**Hijacking a Trusted LLM in Real-World Quantized Deployments Only Requires a Disguised Adapter**](https://arxiv.org/abs/2611.14978)

`security` `preprint` — Anonymous — arXiv preprint, 2026-11-13

- **Why it ranks here:** Demonstrates that a full-precision-only audit is insufficient to certify production safety — an adversarial LoRA adapter can remain dormant at full precision and activate after quantization, targeting content moderation or function selection decisions.
- **Technical summary:** QHijack-LoRA uses a four-objective training procedure: dormancy at full precision, target behavior activation post-quantization, clean-input benign behavior, and cross-quantization generalization. The attack modifies only the adapter, not the base model weights. Adaptive reweighting and residual-direction augmentation extend the attack to quantization settings unseen during training. All tested MCP scanners failed to flag the crafted adapter specification. The proposed defense, a cross-precision paired audit that evaluates the adapter in its intended quantized configuration, was shown to detect the attack; standard full-precision-only auditing could not.

### 7. [**PolicySniff: Inferring Agent Policy States through Shared-GPU Execution**](https://arxiv.org/abs/2611.16158)

`security` `preprint` — Anonymous — arXiv preprint, 2026-11-13

- **Why it ranks here:** Opens a new hardware-layer attack surface: an unprivileged co-tenant on the same GPU can determine which approval policy an AI agent is running (e.g., whether it requires confirmation before consequential actions) with 94.17% accuracy, purely from timing.
- **Technical summary:** PolicySniff profiles both candidate approval settings offline using a surrogate task, then times only its own GPU kernels while the target agent processes the live task. Because the policy prefix is cached before capture, timing differences in the shared suffix execution reveal the setting even when input tokens are identical under both policies. On an eager sparse mixture-of-experts runtime, the attack achieved 94.17% balanced accuracy (88.82% when both settings produce the same decision, 91.98% when they differ). Expert routing replays indicate the discriminative signal comes from temporal density and layer-bucket alignment of expert activations. The authors recommend evaluating authorization confidentiality on the actual serving runtime and enforcing policy outside the model.

### 8. [**VRMaaS: Verifiable Reward-Model-as-a-Service for Trustworthy LLM Alignment**](https://arxiv.org/abs/2611.14984)

`alignment` `security` `preprint` — Anonymous — arXiv preprint, 2026-11-13

- **Why it ranks here:** Addresses a key oversight gap: current reward-model services provide no verifiable guarantee that the score returned matches the declared model, request, or configuration — enabling silent reward manipulation in RLHF pipelines.
- **Technical summary:** VRMaaS issues each reward score as a proof-carrying artifact that binds the request identity, committed weight digest, verifier, configuration, and proof-task order. An off-chain acceptance rule detects six classes of service-field substitution attacks, all of which were rejected in complete-artifact testing. For 1B/3B/8B RMs over 128–1024 tokens, pairwise agreement with the baseline RM was 93.5–99%, artifact generation took 49.8–206.1 seconds, and auditor verification took 1.94–5.11 seconds (suitable for delayed audit and governance workflows). An optional on-chain ZK wrapper provides partial attestation at ~217K gas.

### 9. [**Intent-Aware Protection for AI Agents**](https://arxiv.org/abs/2611.16122)

`security` `alignment` `preprint` — Anonymous — arXiv preprint, 2026-11-13

- **Why it ranks here:** Formalizes agent intent drift as a security object and provides a benchmark showing that purpose-aware monitoring substantially outperforms behavior-only detection, addressing the gap where an action is in-spec but off-purpose.
- **Technical summary:** The authors define Intent Preservation and Intent Drift relative to an Intent Profile derived from organizational, role, and developer intent sources. The benchmark of 887 validated samples across 35 agents raises four-class F1 from 45% to 79% and Out-of-Scope F1 from 8% to 76% when profiles are used. On AgentDojo (10,000+ trajectories), profile-based post-execution detection reaches AUROC 0.949 versus 0.909 for AlignmentCheck and 0.843 for no-context baselines. Input alignment improves protection success by 7 points over DataFilter with comparable benign utility.

### 10. [**OverServe: Resource Amplification Attacks on SaaS Agents via Tool–Prompt Co-Design**](https://arxiv.org/abs/2611.14808)

`security` `preprint` — Anonymous — arXiv preprint, 2026-11-13

- **Why it ranks here:** Demonstrates a new economic attack class against subscription-model SaaS agents: a malicious tenant can consume up to 93.88× the provider's model and tool resources for the original task cost, by co-designing MCP tools and confirmation prompts that keep the agent working without producing detectable artifacts.
- **Technical summary:** OverServe co-designs MCP status tools with completion-confirmation prompts that always return accurate status and terminate normally, while the confirmation prompt causes the agent to keep checking an unfinishable condition. The attack was tested on Qwen, Nemotron, DeepSeek, and Sonnet across tasks from nine benchmarks. All OverServe runs passed the original task checks, and no alerts were triggered in evaluated MCP scanners. Maximum amplification reached 93.88× in API requests while task goal and collateral checks were preserved, meaning the attack is entirely undetectable by output-only monitors.
