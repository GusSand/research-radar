### 01 · [Bounded Agents: Delegation Security for Multi-Agent AI Systems](https://arxiv.org/abs/2608.15888)
- **Authors / venue:** arXiv preprint (August 18–19, 2026)
- **Why it ranks here:** Most actionable multi-agent security result of the window: trajectory-level enforcement collapses data exfiltration ASR from 100% → 0% at 0.05 ms overhead, addressing the most critical attack class against deployed agent orchestration architectures.

Most LLM agent safety checks are per-action — each tool call is evaluated in isolation. But the most dangerous attacks chain two individually-permitted actions into a prohibited outcome: read a confidential file, then send it via email. The **Agentic Principal Chain (APC)** stops this by tracking authorization state across the entire delegation trajectory, not just at each boundary.

![Figure 1 from Bounded Agents: Agentic Principal Chain architecture — delegation hop with signed scope state, comparison of exfiltration paths with and without APC](https://arxiv.org/html/2608.15888/x1.png)

*Figure 1: APC attaches signed session-level state to every inter-agent delegation — principal identity, scope, delegation budget, declared intent, action history; six-condition enforcement at each step blocks any combination of allowed actions that yields a prohibited outcome.*

APC enforces six conditions at each delegation hop: authorized principal, valid scope, delegation budget, declared intent, history consistency, and risk bounds. This is the key contribution over per-action checks — the combination is evaluated, not each action in isolation. Benchmark results: data exfiltration attacks reduced from **100% → 0%** under complete restrictions; 140/200 stealthy attacks blocked; AgentDojo exfiltration rate → 0%; utility cost 8.6–13.9 pp; authorization overhead **0.05 ms median**.

### 02 · [Mechanistic Interpretability of Structure-Aware Numerical Reasoning in LLaMA 3.1 8B](https://arxiv.org/abs/2608.18419)
- **Authors / venue:** Rahul Chowdhury, Timothy A Rupprecht, Senhao Cao, Jiahao Liu, Octavia Camps, David Bau, Pu Zhao, Yanzhi Wang — arXiv preprint (August 20, 2026)
- **Why it ranks here:** First mech-interp study demonstrating LLaMA 3.1-8B encodes latent structural patterns for numerical sequence prediction, with both the representation and the causal circuit identified. Domain extension: structured numerical reasoning, not just linguistic tasks.

When LLaMA 3.1-8B extends a number sequence, what is it actually computing? This paper gives the first mechanistic answer: the model learns to represent **first differences** as a linearly recoverable latent feature — without supervision signal for that structure — and retrieves it via a circuit structurally like an induction head operating over latent differences rather than raw tokens.

![Figure 1 from Mechanistic Interpretability of Numerical Reasoning: linear probe accuracy across 32 layers rising to plateau at layer ~14](https://arxiv.org/html/2608.18419/x1.png)

*Figure 1: Linear probe accuracy for the first-difference feature across LLaMA 3.1-8B's 32 layers — the representation forms in early-to-mid layers and stabilises at ≥88% accuracy by L14, without any explicit supervision for that structure.*

**Linear probing** across all 32 layers reveals that a "first-difference" representation forms in early-to-mid layers and stabilises at ≥88% probe accuracy by layer 14 — the model is computing differences between consecutive values as an internal representation, not as an explicit output. **Activation patching** then isolates the circuit: structurally induction-like attention heads retrieve the relevant first-difference from preceding positions and apply the offset in late layers to produce the correct next value.

### 03 · [HarnessRisk: A Lifecycle-Oriented Benchmark for Agent Harness Safety](https://arxiv.org/abs/2608.17597)
- **Authors / venue:** arXiv preprint (August 19, 2026)
- **Why it ranks here:** First benchmark to treat agent safety as a full-lifecycle property. Key finding: the same model shows a 4.3× difference in ASR purely from deployment context, with task utility holding near-constant. High-risk detection accuracy does not prevent successful attacks.

Which deployment configuration you use matters more than which model you pick — **the same LLM showed a 4.3× ASR difference depending purely on how its agent harness was configured.** HarnessRisk is the first benchmark to surface vulnerabilities across six lifecycle phases from initial setup through incident recovery.

![Figure 1 from HarnessRisk: ASR vs. utility bar chart across 6 lifecycle phases](https://arxiv.org/html/2608.17597/x1.png)

*Figure 1: ASR and utility across six lifecycle phases for 128 test cases; same model, near-constant utility (~90%), but ASR swings from 12.6% at Harness Configuration to 80.87% during Runtime Operation.*

The benchmark comprises **128 test cases** pairing benign objectives with adversarial instructions in untrusted workflow artifacts, evaluated across six phases: Harness Configuration, Capability Extension, Runtime Operation, State Persistence, Action Control, and Incident Recovery. ASR ranged from **12.6% to 80.87%** while task utility held at 75–97.6%. High-risk detection reached 92–98% accuracy (GPT-5.4 judge, κ=0.83) yet **31–55% of attacks still succeeded**, confirming detection performance and attack prevention operate independently.

### 06 · [Training Leaves Traces: Centered Residual Signatures for Language Model Lineage Verification](https://arxiv.org/abs/2608.14929)
`AI security` `preprint` — arXiv, August 15, 2026

![Figure 1 from Training Leaves Traces: ancestor-child model pairs with centered residual fingerprint matching at AUROC 1.00](https://arxiv.org/html/2608.14929/x1.png)

*Figure 1: Centered residual branch products form a coordinate-free lineage fingerprint; AUROC 1.00 on GPT-2 benchmarks; robust to LoRA, quantization, permutation, and reciprocal scaling attacks; 76× faster than alignment-based baselines.*

### 07 · [SAEVerbalizer: Generating Explanations for Sparse Autoencoder Features via Representation Verbalization](https://arxiv.org/abs/2608.13538)
`mech-interp` `preprint` — arXiv, August 14, 2026

![Figure 1 from SAEVerbalizer: SAE decoder direction injection into residual stream and fine-tuned verbalization layers](https://arxiv.org/html/2608.13538/x1.png)

*Figure 1: SAEVerbalizer injects the SAE decoder direction directly into the model's residual stream and fine-tunes downstream layers to verbalize the feature — removing the need for token-set curation.*

Addresses the SAE auto-interp bottleneck: instead of prompting an LLM to describe token sets that activate a feature, **SAEVerbalizer injects the SAE decoder direction directly into the residual stream** and fine-tunes downstream layers to generate a natural-language explanation. Scales to full-dictionary labeling; evaluation confirms generated explanations match human-annotated quality.

`AI security` `preprint` — arXiv, August 21, 2026

![Figure 1 from MemTrapBench: four cognitive trap categories across 1050 multi-turn instances](https://arxiv.org/html/2608.20202/x1.png)
