## 01 · [Dynamic Deep Prompt Optimization for Defending Against Jailbreak Attacks on LLMs](https://arxiv.org/abs/2609.26185)

`AI security` `jailbreak-defense` `preprint` — Doniyorkhon Obidov, Honggang Yu, Xiaolong Guo, Kaichen Yang — arXiv, late September 2026

DDPO is the first jailbreak defense based on deep prompt optimization, using the target LLM's own intermediate layers as feature extractors to dynamically generate defensive embeddings via a lightweight MLP — avoiding expensive fine-tuning and outperforming static prompt-based defenses across attack types.

![Figure 5: DDPO architecture — intermediate LLM layers as feature extractors feeding a lightweight MLP that generates dynamic defensive embeddings](https://arxiv.org/html/2609.26185/x1.png)

*Figure 5: DDPO defense pipeline: intermediate LLM hidden states → lightweight MLP → dynamic defensive prompt embedding prepended to input; adapts defenses per-query rather than relying on a static prefix.*

## 02 · [HE-Guardrail: A Homomorphic Guardrail Against Jailbreak Attacks for Encrypted Large Language Model Inference](https://arxiv.org/abs/2609.21484)

`AI security` `privacy-preserving ML` `encrypted inference` `preprint` — Byeongseo Min, Yongwoo Lee, Young-Sik Kim, Yongjune Kim — arXiv, September 18, 2026

In homomorphic-encryption-based LLM serving the server cannot inspect plaintext prompts — but this also prevents it from blocking jailbreaks; HE-Guardrail solves this by running guardrail evaluation entirely over encrypted data, the first framework to do so.

![Figure 6: HE-Guardrail system diagram — client encrypts prompt, server evaluates guardrail over HE ciphertext, blocks jailbreak without decrypting](https://arxiv.org/html/2609.21484/x1.png)

*Figure 6: HE-Guardrail: encrypted prompt → homomorphic guardrail evaluation → conditional block or pass to encrypted LLM; server never accesses plaintext yet achieves reliable jailbreak detection.*

## 03 · [Topographic Training Concentrates Causal Circuits Without Improving Neuron Monosemanticity](https://arxiv.org/abs/2609.24379)

`mech-interp` `causal-circuits` `SAE` `ICML 2026 MI Workshop (peer-reviewed)` — Gautam Ranka, Shubham Santosh Pandere, Aiden Dsouza — ICML 2026 Mechanistic Interpretability Workshop

Spatial-locality training (TopoLoss) makes clusters 2.79× more causally sufficient than random unit sets while leaving neuron-level monosemanticity scores unchanged — topographic pressure organizes circuits, not individual neurons, with implications for interpretability tooling.

![Figure 7: Causal sufficiency vs monosemanticity scatter — topographic clusters high on causal axis but overlapping on monosemanticity axis](https://arxiv.org/html/2609.24379/x1.png)

*Figure 7: At α=1.0, topographic clusters are 2.79× more causally sufficient than random unit sets; SAE L0 sparsity decreases 11% and dead-feature fraction rises 19-fold, yet standard neuron monosemanticity scores are unchanged — topographic pressure acts at circuit level.*

## 04 · [Certified Mechanistic Interpretability: Lifting Single-Input Findings to Bounded Neighbourhoods](https://arxiv.org/abs/2609.26112)

`mech-interp` `formal-verification` `preprint` — (authors not retrieved) — arXiv, late September 2026

Single-input mechanistic interpretability findings (e.g., "attention head H attends to subject token") are brittle — a nearby input may break them. This paper provides the first formal certificate lifting such findings to bounded input neighbourhoods using constrained polynomial-zonotope (CPZ) propagation through transformer blocks.

![Figure 8: CPZ propagation diagram through transformer blocks — single-input finding lifted to certified ε-neighbourhood](https://arxiv.org/html/2609.26112/x1.png)

*Figure 8: CPZ propagation preserves the softmax simplex and LayerNorm zero-mean identity exactly through each block; a recursive Jacobian zonotope extends certificates across layer depth, converting single-point observations into neighbourhood-certified mechanistic claims.*

## 05 · [SAEScientist-Bench: Can AI Agents Conduct Autonomous SAE Interpretability Research?](https://arxiv.org/abs/2609.09113)

`mech-interp` `SAE` `AI-agents` `preprint` — Yuqiao Tan, Shizhu He, Jun Zhao, Kang Liu — arXiv, September 8, 2026

Benchmark evaluating whether frontier AI agents can autonomously navigate a 131K-feature Gemma Scope dictionary to discover SAE features for target concepts; agents approach expert levels on contrastive feature separation but lag substantially on causal-generation steering.

![Figure 9: Radar chart comparing agent vs expert performance across SAEScientist-Bench dimensions](https://arxiv.org/html/2609.09113/x1.png)

*Figure 9: Across 10 agent configurations and 20 tasks, frontier agents demonstrate genuine discovery capabilities but remain well behind expert baselines — especially on causal generation steering — and frequently misinterpret experimental measurements.*
